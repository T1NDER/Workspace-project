## Workspace Dashboard (Тестовое задание, 13-поток)

### 📚 О проекте
**Workspace Dashboard** — это тестовое задание для frontend-разработчика. Проект представляет собой страницу рабочего пространства команды, где пользователи могут просматривать статистику, активные проекты, задачи, участников команды и ленту активностей. Ключевой программной частью является компонент с автоматической ротацией 2-ух уникальных активных проектов из списка 10-ти элементов.

### 💡 Цель
Цель проекта — Выполнить поставленную задачу, а также продемонстрировать навыки компонентного подхода в React, работу с состоянием и побочными эффектами, строгую типизацию на TypeScript, а также умение писать чистый, структурированный и поддерживаемый CSS-код.

### 🛠 Выполненная работа
- Спроектирована и реализована четкая иерархия компонентов (Header, Main, Footer, Sections).
- Написан кастомный хук для автоматической циклической ротации элементов с возможностью постановки на паузу.
- Настроена строгая типизация всех пропсов и данных с помощью TypeScript.
- Реализована модульная CSS-архитектура по методологии БЭМ с использованием CSS-переменных и подключенных локальных шрифтов (Montserrat).
- Настроен алиасинг путей в Vite и TypeScript для удобства разработки.
- Проект полностью адаптирован под различные размеры экранов и подготовлен к деплою.

### 🛠 Технологии

| Технология | Описание |
|---|---|
| **React** | Построение пользовательского интерфейса и управление состоянием компонентов |
| **TypeScript** | Статическая типизация для надежности кода и удобства рефакторинга |
| **Vite** | Быстрая сборка проекта и локальный сервер разработки |
| **CSS** | Стилизация, адаптивная вёрстка, кастомные свойства, локальные шрифты |
| **GitHub Pages** | Размещение и публикация собранного приложения |

### 🚀 Запуск проекта
1. Клонирование репозитория: `git clone <url-репозитория>`
2. Переход в папку проекта: `cd workspace-project`
3. Установка зависимостей: `yarn install` (или `npm install`)
4. Запуск в режиме разработки: `yarn dev` (или `npm run dev`)
5. Сборка для продакшена: `yarn build`
